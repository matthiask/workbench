# Tastaturkürzel

Tastaturkürzel verwenden auf Macs <kbd>Ctrl</kbd> und sonst <kbd>Alt</kbd>;
die Tasten unten sind für deinen Computer angegeben. Der Plus-Knopf unten
links auf jeder Seite bietet die häufigsten Aktionen ebenfalls an, mit
ihren Tastaturkürzeln.

| Tastaturkürzel | |
| --- | --- |
| <kbd>Ctrl-Q</kbd> | Alles durchsuchen |
| <kbd>Ctrl-F</kbd> | Ins Suchfeld einer Liste |
| <kbd>Ctrl-Return</kbd> | Das aktuelle Formular absenden |
| <kbd>Ctrl-H</kbd> | Startseite |
| <kbd>Ctrl-C</kbd> | Personen |
| <kbd>Ctrl-Shift-C</kbd> | Zu einer Person springen |
| <kbd>Ctrl-P</kbd> | Projekte |
| <kbd>Ctrl-Shift-P</kbd> | Zu einem Projekt springen |
| <kbd>Ctrl-O</kbd> | Offerten (mit Zugriff aufs Controlling) |
| <kbd>Ctrl-R</kbd> | Rechnungen (mit Zugriff aufs Controlling) |
| <kbd>Ctrl-D</kbd> | Geschäfte (mit Zugriff auf Geschäfte) |
| <kbd>Ctrl-T</kbd> | Zeitmarken |
| <kbd>Ctrl-L</kbd> | Stunden auf dem angezeigten Projekt erfassen, sonst auf irgendeinem |
| <kbd>Ctrl-Shift-L</kbd> | Stunden auf irgendeinem Projekt erfassen |
| <kbd>Ctrl-K</kbd> | Kosten auf dem angezeigten Projekt erfassen, sonst auf irgendeinem |
| <kbd>Ctrl-Shift-K</kbd> | Kosten auf irgendeinem Projekt erfassen |
| <kbd>Ctrl-B</kbd> | Eine Pause erfassen |
| <kbd>Ctrl-Shift-B</kbd> | Pausen |
