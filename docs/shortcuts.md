# Keyboard shortcuts

Shortcuts use <kbd>Ctrl</kbd> on Macs and <kbd>Alt</kbd> elsewhere; the
keys below are shown for your computer. The plus button at the bottom
left of every page offers the most frequent actions with their
shortcuts too.

| Shortcut | |
| --- | --- |
| <kbd>Ctrl-Q</kbd> | Search everything |
| <kbd>Ctrl-F</kbd> | Into the search field of a list |
| <kbd>Ctrl-Return</kbd> | Submit the current form |
| <kbd>Ctrl-H</kbd> | Start page |
| <kbd>Ctrl-C</kbd> | People |
| <kbd>Ctrl-Shift-C</kbd> | Jump to a person |
| <kbd>Ctrl-P</kbd> | Projects |
| <kbd>Ctrl-Shift-P</kbd> | Jump to a project |
| <kbd>Ctrl-O</kbd> | Offers (with access to controlling) |
| <kbd>Ctrl-R</kbd> | Invoices (with access to controlling) |
| <kbd>Ctrl-D</kbd> | Deals (with access to deals) |
| <kbd>Ctrl-T</kbd> | Timestamps |
| <kbd>Ctrl-L</kbd> | Log hours on the project you're looking at, else on any project |
| <kbd>Ctrl-Shift-L</kbd> | Log hours on any project |
| <kbd>Ctrl-K</kbd> | Log costs on the project you're looking at, else on any project |
| <kbd>Ctrl-Shift-K</kbd> | Log costs on any project |
| <kbd>Ctrl-B</kbd> | Log a break |
| <kbd>Ctrl-Shift-B</kbd> | Breaks |
